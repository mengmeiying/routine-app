# Рутина

PWA-чеклист утренней и вечерней рутины. Главная задача — показать, какое дело делать
прямо сейчас, чтобы не вспоминать порядок. Приложение само выбирает утро или вечер по
времени, крупно показывает текущее дело и работает офлайн.

**Открыть:** https://mengmeiying.github.io/routine-app/

Приложение рассчитано на телефон (основной экран 360–420px). В Chrome на Android его можно
установить на главный экран: меню → «Установить приложение».

## Как это работает

- **Логический день** идёт с 06:00 до 06:00. Всё, что сделано в 02:00, относится ко «вчера».
- **Утро** с 06:00 до 18:00, **вечер** с 18:00 до 06:00. Показывается только текущая рутина.
- **Текущее дело** — первое невыполненное в очереди, показано крупно, остальные мелко.
- **«Готово»** отмечает дело выполненным, **«Сделаю позже»** переносит его в конец очереди.
- Когда всё сделано, показывается экран «Всё готово».
- Отметки сбрасываются в 06:00. История по дням сохраняется в `localStorage`.
- Светлая и тёмная тема подстраиваются под настройки телефона.

Список дел лежит в [`src/data/tasks.ts`](src/data/tasks.ts): порядок в массиве — порядок
выполнения, дело с `enabled: false` не показывается.

## Стек

- React, Vite, TypeScript
- `vite-plugin-pwa`: манифест, service worker, офлайн-кэш
- CSS Modules, без UI-библиотек и CSS-фреймворков
- Vitest и Testing Library
- ESLint и Prettier
- GitHub Actions и GitHub Pages

## Запуск

Нужен Node 22.

```bash
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173/routine-app/`: путь `/routine-app/`
задан в `vite.config.ts` для GitHub Pages.

| Команда           | Что делает                          |
| ----------------- | ----------------------------------- |
| `npm run dev`     | dev-сервер                          |
| `npm run build`   | проверка типов и сборка в `dist/`   |
| `npm run preview` | локальный просмотр собранной версии |
| `npm test`        | все тесты                           |
| `npm run lint`    | ESLint                              |
| `npm run format`  | Prettier                            |

## Структура

```
src/
  data/tasks.ts      список дел
  lib/               чистая логика без React
    logicalDay.ts    дата логического дня
    routine.ts       утро или вечер по времени
    queue.ts         очередь, «Готово», «Сделаю позже»
    storage.ts       единственное место, которое обращается к localStorage
  hooks/useNow.ts    текущее время для интерфейса
  components/        экраны и кнопки
docs/ROADMAP.md      план и бэклог
```

Логика отделена от React и покрыта тестами, особенно границы времени: 05:59, 06:00,
17:59, 18:00, 00:00. Компоненты работают с хранилищем только через `storage.ts`, поэтому
позже его можно заменить на API, не трогая остальной код.

## Деплой

При пуше в `main` GitHub Actions ставит зависимости, прогоняет `lint` и тесты, собирает
проект и публикует `dist/` на GitHub Pages. Если любая проверка падает, на сайте остаётся
предыдущая рабочая версия. Описание — в
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

## Как разрабатывалось

Проект сделан вместе с [Claude Code](https://claude.com/claude-code). Правила работы
записаны в [`CLAUDE.md`](CLAUDE.md), оттуда же взяты доменные правила и границы того, что
в проекте пока не делается.

- Работа шла маленькими шагами: перед заметным изменением Claude описывал план,
  дальше план подтверждался или правился.
- Зависимости добавлялись только с моего согласия.
- Каждый шаг заканчивался `lint`, тестами и сборкой, а интерфейс проверялся в браузере.
- Коммиты делались только после моего подтверждения, в стиле Conventional Commits.
- Новые идеи уходят в бэклог, а не в текущую версию.
